usbip-browser

A USB/IP client in the browser. No WebUSB involved.

Source

Ready. Mock mode needs no setup — just connect.

Mock mode runs an in-browser USB/IP server that emits real wire bytes through the same codec as the network path. Live mode reaches a real usbipd through relaynet: run relaynet-bridge -expose 3240 next to it and enter the address it logs. Needs a relaynet beta account; nothing listens on the internet.
